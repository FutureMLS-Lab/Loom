# Personal skills

This file is the bundled default *selection* - injected only when a task's
skills picker points at it (which is the default). The behavioural floor
every agent gets regardless lives in `DEFAULT_PROMPT.md`; do not copy it
here.

What belongs here instead: the things only your setup knows. Replace the
examples below with your own.

## Compute
- Where experiments run: this machine, or which cluster / context / queue.
- Where shared caches and datasets live (models, HF cache, scratch).

## Git conventions
- Branch and worktree naming.
- Whether agents may commit or open PRs without being asked.

## Style
- Language and formatting preferences for results and reports.
